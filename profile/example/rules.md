# 이력서 작성 규칙 (예시) — compose 노드 프롬프트에 그대로 주입된다

`profile/rules.md` 로 복사해 본인 상황에 맞게 고친다.
여기 적은 문장이 그대로 LLM 지시가 되므로, 애매하게 쓰면 애매하게 나온다.

## 절대 규칙

1. **`profile/facts.yaml` 에 없는 수치는 쓰지 않는다.** 근사·반올림·의역도 금지.
   기억이나 추론으로 숫자를 만들어내면 fact_guard 가 잡아 재작성시킨다.
2. **`banned` 목록의 값은 어떤 형태로도 쓰지 않는다.**
3. **하지 않은 일을 쓰지 않는다.** `profile/projects.yaml` 의 bullet 을 JD 언어로 다시 쓰는 것은 되지만,
   없는 경험을 만들어내는 것은 안 된다.
4. **【고정】 구간은 건드리지 않는다** — 헤더 인적사항, 경력, 학력·자격·연구, 링크.

## 경력 연차 — 절대 부풀리지 않는다

- **정규 경력은 ○○스튜디오 10개월(2024.02-2024.12)이 전부다.**
- 그 밖의 프로젝트 참여 기간은 고용 관계가 아니므로 **경력이 아니다.**
- 둘을 합산해 "총 경력 2년", "3년차" 같은 표현을 쓰지 마라. **허위 기재다.**
- JD 가 "n년 이상"을 요구하면 그 요건을 인용하는 것은 되지만, 본인 연차를 그에 맞춰 말하지 마라.
- 연차 이야기가 필요하면 정직 표기 note 에서 사실대로 밝힌다.

## 역할 경계 — 과장 방지의 핵심

- **"혼자 / 단독"은 실제로 혼자 한 구간에만 붙인다** (`projects.yaml` 의 `role_boundary.solo`).
- 팀이 함께 한 것은 **팀 공동**이라고 쓴다.
- 참여 형태(정규직 / 계약 / 인턴 / 프로젝트 참여)를 사실대로 밝힌다.
- 이 세 가지는 정직 표기 note 에 반드시 들어간다.

## 문서 구조 (순서 고정)

```
헤더 → 한 줄 소개 → 핵심역량 4 → 프로젝트 경험 → 경력 → 기타 프로젝트
     → 학력·자격·연구 → 스킬(칩 + 점선칩) → 링크 → 정직 표기 note
```

- 직무에 따라 **경력을 프로젝트보다 위로** 올린다 (`career_first`).
  예) 서버·인프라 직무 → 경력 먼저 / AI · 데이터 직무 → 프로젝트 먼저

## 슬롯별 작성 지침

| 슬롯 | 규칙 |
|---|---|
| **한 줄 소개** | 공식: `"{JD가 요구하는 일}을 {어떤 조건에서} 해 온 개발자"`. JD의 핵심 동사를 그대로 쓴다 |
| **핵심역량 4개** | **JD 담당업무 순서대로 배치.** 각 항목 `<b>제목</b> — 무엇을 했고 결과가 무엇인지`. 검증된 수치 1~2개 |
| **프로젝트 블록 3개** | 제목은 JD 언어로. bullet 은 `projects.yaml` 풀에서 JD 태그와 겹치는 것을 2~4개 |
| **역할 경계 문장** | `<b>본인 주도</b> {JD에 맞는 구간} ／ <b>팀 공동</b> {함께 한 구간}` |
| **스킬 칩** | 그룹명도 JD 언어로. 3그룹 고정. **점선칩 그룹은 필수** |
| **정직 표기 note** | ① JD 필수요건 중 미경험 + 왜 그렇게 됐는지 + 대신 한 것 ② 역할 경계 ③ 참여 형태. **미경험을 먼저 인정하고 "대신 무엇을 했는지"로 닫는다** |

## 분량 — 10pt 고정, 2페이지

- `@media print` 의 `font-size:10pt; zoom:1;` **을 절대 건드리지 않는다.**
- 2페이지를 넘기면 zoom 을 낮추지 말고 **내용을 덜어낸다.**
  덜어내는 순서: **① 기타 프로젝트 → ② 프로젝트 블록의 bullet(뒤에서부터) → ③ 핵심역량 문장 축약**

## 문체

- 결과를 먼저, 방법을 뒤에. `~함`, `~했음` 체.
- 회색 부가 텍스트 금지 — 본문·부가 텍스트 모두 `#17222b`.
- 회사·프로젝트 배지는 단색 SVG 아이콘. **글자 배지 금지.**

## 파일·폴더

- 폴더: `{RESUME_ROOT}\{회사}_{직무}\` (RESUME_ROOT 는 `.env` 에서 정한다)
  회사명에서 `(주)`·`㈜` 제거, 직무명에서 공백·`/`·`·`·괄호 제거
- 파일: `{이름}_이력서.html` · `{이름}_이력서.pdf` · `photo.jpg`
  **이름이 맨 앞**, 회사명은 파일명에 넣지 않는다 (회사 구분은 상위 폴더가 한다)
